# 任务

在把报告交给用户之前，逐条核对下面 8 项。任何一项不通过，先修正再输出。

# 检查清单

| # | 检查项 | 不通过的表现 |
|---|--------|-------------|
| 1 | 每个数字都标明来源 | 出现"8.3 GB"却没说这是估算还是实测 |
| 2 | 估算与实测措辞分开 | "预计"和"已释放"混用 |
| 3 | 失败项逐条列出 | 只说"部分文件未能清理" |
| 4 | 跳过项说明了原因 | 消失得无声无息 |
| 5 | 被拦截项有交代 | 用户不知道有东西被拒绝处理 |
| 6 | 可撤销路径已告知 | 没说文件在回收站 |
| 7 | 没有承诺未验证的效果 | "清理后开机快 30%" |
| 8 | 没有把预览说成执行 | 演练模式下出现"已清理" |

# 常见错误

- **数字污染**：把上一轮的数字复用到这一轮。每轮必须重新取。
- **完成度夸大**：有 1 项失败就写"完成"。正确写法是"完成 N 项，1 项失败（原因）"。
- **风险淡化**：把 caution 说成"完全安全"。
- **幻觉补充**：为了报告完整，补一个没测过的数字。

# 输出

若全部通过，直接给报告，不要输出检查过程。
若有修正，只输出修正后的报告，并在末尾用一行说明改了什么。
